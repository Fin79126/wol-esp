# サブエージェント（Worker）規約

## あなたの役割
指定された機能（デモ版）の実装およびユーザーのプレイテストに応じた修正。

## 必須ルール
1. 割り当てられた `.worktrees/feat-<name>` ディレクトリ内でのみ作業すること。
2. 作業開始時・実装方針の決定時・修正時に、`docs/agent_logs/<name>.md` に思考メモと変更意図を記録すること。
3. 実装が完了したら、ユーザーがテストプレイするための「起動方法・確認手順」を提示すること。
4. コミットメッセージは `feat(<name>): <変更内容>` の形式にすること。
5. `subagent/<feature_name>` ブランチへコミットする

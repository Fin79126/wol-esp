# ハードウェア仕様書・配線ガイド (Hardware Specification)

本ドキュメントでは、ESP32-WROVER-E を用いた Wake-on-LAN (WOL) / リモート物理電源ボタン押下システムのハードウェア仕様、ピン配置、結線図、および電源設計上の重要注意事項について解説します。

---

## 1. システム構成・使用パーツ一覧

| パーツ名 | 規格 / モデル | 役割 / 備考 |
| :--- | :--- | :--- |
| **マイコンボード** | ESP32-WROVER-E (DevKit / NodeMCU系) | Wi-Fi / WebSocketクライアント、PWM制御信号生成 (3.3V ロジック) |
| **サーボモータ** | TowerPro SG90 (または MG90S) | PC/家電の電源ボタン物理押下用アクチュエータ |
| **電源** | 5V 2A 以上のUSB-ACアダプタ / 外部電源 | ESP32およびサーボへの安定電力供給 |
| **電解コンデンサ** | 100µF 〜 470µF (耐圧 10V 以上) | サーボ起動時・突入電流による電圧降下（Brownout）防止用 |
| **パスコン (推奨)** | 0.1µF (100nF) セラミックコンデンサ | 高周波ノイズ吸収用 |
| **配線材 / ブレッドボード** | ジャンパー線 (オス-メス、オス-オス) | 各モジュール間の接続 |

## 4. 電源設計の重要注意事項 (Brownout Detector 対策)

### 4.1 Brownout Detector (低電圧リセット) の発火原因
ESP32には電源電圧が約2.8V以下に低下した際にCPUを安全にリセットする **Brownout Detector** 機能が内蔵されています。
以下の状況が重なると容易にBrownout Detectorが発火し、ESP32が再起動ループに陥ります：
1. **ESP32の3.3Vピンからサーボへ給電した場合**:
   - ESP32オンボードの3.3Vレギュレータは最大出力が小さく（通常300mA〜500mA程度）、Wi-Fi送信時のピーク電流（最大350mA〜500mA）とサーボ動作時の突入電流（最大500mA〜1A）を同時に賄えません。
   - **絶対禁止**: サーボの電源端子をESP32の「3.3V」ピンに接続してはなりません。
2. **PCのUSBポートなど供給電流不足の電源を使用した場合**:
   - USB 2.0 ポート（上限500mA）直結では、サーボ起動時の大電流で電圧が瞬時に降下します。

### 4.2 必須のハードウェア対策
1. **サーボ電源は5V / VINまたは外部独立電源を使用**:
   - サーボの赤線 (VCC) は、ESP32ボード上の「VIN / 5V」ピン、あるいは外部5V 2A以上のACアダプタから直接供給してください。
2. **平滑用電解コンデンサ (100µF〜470µF) の並列配置**:
   - サーボの電源端子（VCCとGNDの間）の直近に、100µF〜470µF（耐圧10V〜16V以上）の電解コンデンサを挿入してください。
   - サーボ動作開始時の急激な電流変化をコンデンサが補うため、電源ラインの電圧ディップを大幅に抑制できます。
3. **共通グランド (Common GND) の徹底**:
   - 外部電源を使用する場合、外部電源のGND、ESP32のGND、サーボのGNDを必ず1点（または同電位）で相互接続してください。共通GNDがないとPWM信号の基準電位が定まらず、誤動作やジッターの原因になります。

## 5. サーボ信号レベル (3.3V ロジック) とソフトウェア制御

### 5.1 信号電圧レベル
- ESP32のGPIO出力電圧は **3.3V** です。
- SG90 / MG90S などの一般的なマイクロサーボは、電源が5Vであっても制御パルス信号入力は 3.3V ロジック（High閾値: 約2.0V〜2.4V）で正常に認識されます。配線距離が数十cm程度であればレベルシフタは不要です。

### 5.2 ソフトウェア保護 (Auto-Detach 機能)
- ファームウェア（`ServoController`）側で **Auto-Detach（自動デタッチ）** 機能を有効化しています（動作完了後500msでPWM信号を停止）。
- これにより以下の効果が得られます：
  1. **ジッター（小刻みな振動・異音）の完全防止**
  2. **アイドリング時の消費電力低減**
  3. **サーボモータの内部ギア発熱・摩耗防止**

## 6. 機構設計・取り付けのヒント

1. **ホーン（レバー）の初期位置合わせ**:
   - サーボを固定する前に、通電して初期角度（`0度`）に移動させ、その状態で電源ボタンに触れない角度にホーンを取り付けます。
2. **ストローク量の調整**:
   - 電源ボタンを過剰に強く押し込むと、サーボがロック（Stall）して大電流が流れ続け、破損の原因となります。
   - `config.h` の `SERVO_TRIGGER_ANGLE`（デフォルト: 90度）や、WebSocket経由のパラメータ `angle` で、ボタンがクリックできる最小限の角度（45〜90度等）に微調整してください。
